# Migrate events, microsites, galleries, and results

## Goal

Preserve the event archive and rebuild event coverage around structured event
and gallery data.

## Scope

- Inventory `/events/` and `/international/` event coverage.
- Classify event hubs, story pages, results, galleries, banners, rotators, and
  documents.
- Preserve legacy URLs for event microsites.
- Build React event archive, event detail, gallery, and media views.

## Acceptance Criteria

- Event pages can be browsed by year, country, region, and ride name.
- Gallery media resolves from the migrated asset manifest.
- Static event documents remain accessible.
- Legacy event URLs redirect or render without broken links.
