# Migrate home, Current News, and Featured Stories

## Goal

Rebuild the highest-visibility editorial surfaces from real legacy content.

## Scope

- Migrate `/index.html`, `/index_content.html`, `/CurrentNews/`, and
  `/FeaturedStories/`.
- Preserve current-news anchors and featured-story deep links where possible.
- Replace placeholder frontend copy and sample data with Endurance.Net content.
- Model homepage slots for current news, featured stories, event coverage,
  sponsor/advertiser blocks, social links, and contact.

## Acceptance Criteria

- The React home page reflects the actual Endurance.Net taxonomy.
- Current News and Featured Stories are driven by imported content records.
- Legacy deep links redirect or resolve correctly.
- Homepage media and sponsor references are available in the asset manifest.
